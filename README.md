# README – Python Programming Projects

## Introduction
This project contains 10 Python programs designed to solve real-world problems using algorithms, flowcharts, pseudocode, and sample outputs.

## Topics

1. **Bus Passenger Occupancy Simulation:** Calculates passenger counts at each bus stop and checks capacity violations.

2. **Hackathon Team Formation and Ranking:** Validates team sizes, calculates scores, and ranks teams based on their performance.

3. **Food Waste Monitoring System:** Calculates leftover meals and wastage percentages to identify excessive food waste.

4. **Multi-Branch Expense Matrix Analysis:** Calculates branch expenses, category totals, and average expenditure using nested lists.

5. **Tuple-Based Transaction Audit:** Detects duplicate transaction IDs, invalid amounts, and suspicious transaction sequences.

6. **Student Group Formation with Score Balancing:** Allocates students into groups and balances their total scores.

7. **Smart Canteen Order and Stock Management:** Processes orders, calculates bills, updates stock, and summarizes sales.

8. **Library Borrowing and Fine Reconciliation:** Calculates overdue fines and tracks book availability.

9. **Campus Transport Allocation:** Calculates the number of buses required and identifies unserved passengers.

10. **Manufacturing Quality Control Matrix:** Calculates defect percentages and identifies batches exceeding quality limits.

## Technologies Used
- Python
- Lists and nested lists
- Tuples and dictionaries
- Loops and conditional statements
- Mathematical calculations

## Conclusion
These programs improve problem-solving and Python programming skills by demonstrating practical applications of basic programming concepts.
